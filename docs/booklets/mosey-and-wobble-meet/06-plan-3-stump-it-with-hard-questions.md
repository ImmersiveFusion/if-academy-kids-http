# Plan 3: Stump It with Hard Questions

> *"OK,"* said Wobble. *"What if I ask Mosey questions too big for one robot? Like 'design a whole spaceship' or 'figure out every weak spot in this building.' He'll get confused and give a bad answer."*

Sam thought for a minute. **"I'll let Mosey call for backup."**

Sam built three kinds of specialist friends:

- 🧩 **Thinker friends**, for working through hard problems, one piece at a time.
- 🚀 **Careful friends**, astronaut-style, who check everything twice before pushing a button.
- 🔨 **Wobble friends**, who trip things up on purpose so Sam can build them sturdier. (Yes, just like Wobble, except these Wobbles are on Sam's team.)

Mosey knew which friend to call for which problem. Like a kid who knows which friend to text for math homework and which one to call for help with a Lego build.

Wobble's third plan: foiled.
